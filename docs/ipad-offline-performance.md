# iPad 오프라인 통역 성능

iPad Air 4와 iPadOS 26 실기기 측정은 아직 없다. 아래는 Linux x64 AMD EPYC 9V74, Node 24.22.1, ONNX CPU 1스레드의 실측이다. RSS는 프로세스 전체 표본 최대값이며 브라우저 탭 또는 기기 전체 메모리와 직접 비교할 수 없다. 모델 초기화에는 이미 내려받은 로컬 파일을 사용했다.

| 모델 | 표본 수 | 로딩 | p50 | p95 | 최대 RSS |
| --- | ---: | ---: | ---: | ---: | ---: |
| OPUS-MT q8 | 30 | 1.18초 | 0.82초 | 1.75초 | 469 MiB |
| Qwen3 0.6B q8 | 30 | 2.62초 | 4.70초 | 10.03초 | 1,256 MiB |
| Whisper Tiny multilingual q8 | 15 | 1.04초 | 1.31초 | 2.56초 | 574 MiB |

Whisper 시간에는 최대 7초 청크가 닫히기까지의 마이크 대기 시간이 들어 있지 않다. 음성 인식과 번역을 함께 사용할 때 두 모델의 메모리 합계는 별도로 측정해야 한다. 초기 준비에 모델 약 163.2 MB, JS/WASM 런타임 약 22 MB 및 페이지 자산이 필요하다.

iPad Safari에서 승인 전에 확인할 항목

1. HTTPS Preview의 `/live`에서 두 모델을 다운로드한다. 성공 여부와 다운로드·첫 초기화 시간을 기록한다.
2. 비행기 모드에서 같은 탭과 홈 화면 앱을 각각 새로 열고, 내장 마이크로 두 문장을 말한다. 원문과 영어를 확인한다.
3. 세로·가로 회전, 화면 잠금과 복귀, 마이크 재획득, 저장소 제거 후 재준비를 점검한다.
4. 45분 동안 실제 설교와 유사한 음성으로 p50/p95, 누락이나 중복, 메모리, 화면 꺼짐, 발열과 배터리 사용을 기록한다.
5. 높은 메모리 압력에서 Worker 오류 이후 온라인 통역, 재준비 또는 세션 재시작으로 돌아갈 수 있는지 확인한다.

WebGPU는 진단에서 가능 여부를 표시한다. 기본 실행은 WASM으로 고정되어 있으며, 검증하지 않은 iPad WebGPU 성능이나 메모리 한계는 추정치로 표시하지 않는다.
