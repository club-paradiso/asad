| ASR 후보 | Qwen/Qwen3-ASR-0.6B-hf | `7f1569a48a89f3e3f4dc3a5c9d28bddd903bc76c` | 브라우저 패키지 미선정 | 공식 체크포인트를 브라우저에서 로드할 경로 미검증 |

고정 리비전과 파일별 해시는 [모델 등록부](../src/providers/offline/models.json)에 있다. Qwen3 번역 q8은 ASAD와 동일한 Transformers.js 3.8.1의 Node CPU 경로에서 직접 실행했다. 원본 ONNX 저장소의 q4 단일 파일은 약 919.1 MB라 이번 실험의 q8보다 컸다. 별도 최적화된 후보는 실험하지 않았다. Qwen3-ASR 모델 카드에서 Transformers 기반 원본 체크포인트를 확인했다. 이 코드는 브라우저용 ONNX 그래프·Korean 전처리·WASM 연산자 지원까지 검증된 배포로 연결하지 않는다.

## 비교 결과

동일한 자체 작성 한국어 입력 10개를 모델마다 세 번 적용했다. 문장 보존을 직접 판독했다. raw 결과와 재현 명령은 테스트 보고서에 있다.

| 점검 | OPUS-MT q8 | Qwen3-0.6B q8 |
| --- | --- | --- |
| 부정 | 회의를 취소하지 않았다는 내용 보존, 시간 변경 주체 모호 | 부정 보존, 변경을 시간 연장으로 구체화 |
| 날짜 | 2026년 11월 28일 09:30 보존 | 11월을 10월로 변경 |
| 수량·금액 | 수량 보존, 배를 선박으로 처리하고 15,000원을 15달러로 바꿈 | 원화 보존, 사과와 배를 사람과 학생으로 변경 |
| 성경 장절 | John 3:16과 읽는 행위 모두 보존 | 장절만 반환 |
| 성경 인명·지명 | Moses, Egypt, Israelites 보존, 인도했다는 의미 약화 | 핵심 인명과 사건 상실 |
| 문맥과 지시어 | 같은 입력 내 그녀와 부정문 보존, 민수·영희 이름 누락 | 관계 일부 보존, 이름 변경 |
| 존댓말 | 재전송 요청 의미 유지, 표현은 간략 | 정중한 표현 보존, 자료를 이사회 구성원으로 오역 |
| 코드 스위칭 | Zoom/Slack 둘 다 보존 실패 | Zoom/Slack 유지, 다음 주 정보 누락 |
| 묶인 문장 | 방문 순서와 시각 보존 | 지명과 돌아오는 행동 변경 |

원화를 숫자로 표기한 경우 로컬 엔진이 모델 입력에서 통화명을 명시하고 출력에서 같은 숫자와 원화 단위를 확인한다. 검증 실패 시 해당 청크를 영어로 표시하지 않는다. 단위가 적혀 있지 않은 숫자, 고유명사, 설교 문체, 앞 턴에서 넘어온 지시어는 실시간 검증되지 않는다. 장절과 용어는 기존 통역 엔진의 부가 정보를 함께 확인한다. 모델은 통역자 보조 용도이며 화면에서 로컬 번역의 한계를 표시한다.
