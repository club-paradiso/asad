# ASAD 오프라인 통역 아키텍처

## 기존 main 감사

기준 커밋은 `65e59b7`이다. Live의 `useLiveSession.ts`가 Web Speech 또는 기존 STT와 마이크를 연결한다. `InterpretationEngine`이 stable 텍스트를 받아 문장, 구, 휴지, 타임아웃 기준으로 턴을 만들고 기존 자막, 수정, 용어 상태를 관리한다. Chrome Translator가 준비된 경우 provisional lane이 영어를 먼저 표시한다. contextual lane은 `cloud-lane.ts`를 통해 `/api/interpret`를 호출한 뒤 커밋된 자막과 늦은 결과를 엔진의 턴 규칙으로 조정한다. 해석 요청은 Zod 계약으로 제한되며, contextual fetch는 턴 전체 예산과 짧은 재시도 간격을 적용한다.

서버 `route.ts`와 LLM router는 자격 증명, 사용 정책과 쿼터에 따라 공급자를 선택한다. 구성된 경우 기존 Gateway recovery를 시도한 뒤 결정론적 보조 출력으로 끝날 수 있다. 이 경로의 HTTP 200과 `provider: local`은 영어 번역 성공을 의미하지 않는다. `factory.ts`, `public-free.ts`, `lib/env.ts`의 공개 배포 제한 및 무료 OpenRouter 예외를 그대로 사용한다. `diagnostics`는 서버 라우팅 상태를, 기존 서비스 워커는 앱 일부와 해시 자산을 캐시했다.

## 로컬 추론과 전환

`cloud-lane.ts`는 기존 provisional lane과 결과 중복을 방지하고, 필요할 때 준비된 OPUS-MT로 전환한다. 로컬 배지가 표시되려면 실제 영어 청크와 Zod 검증을 통과해야 한다. 일일 쿼터 오류는 기존 90분 전환 정책, 일시 쿼터나 공급자가 없는 경우는 짧은 전환 정책을 사용한다. 영어가 생성되지 않으면 원문과 이미 계산된 보조 정보가 남으며 결과 상태가 낮아진다.

로컬 STT는 기존 `MicrophoneCapture`의 AudioWorklet, 리샘플러, 16 kHz mono PCM16을 사용한다. RMS 음성 감지로 0.55초 휴지 또는 최대 7초에서 청크를 닫는다. 모델이 청크를 인식하면 기존 stable 이벤트로 전달한다. 실제 중간 가설을 제공하지 않는 모델이므로 스트리밍 partial 이벤트는 생성하지 않는다. 한 음성 추론과 한 대기 청크를 제한하고 지연 누적으로 유실된 경우 표시한다.

`public/offline-v1/inference.js`는 Worker 안에서 WASM을 한 스레드로 실행한다. 모델별 초기화는 Worker 수명 동안 유지한다. 두 모델이 필요하면 메모리에 함께 남되 추론은 직렬화한다. 취소된 요청의 결과를 무시하며 Worker 오류 또는 추론 타임아웃 시 Worker를 종료해 메모리를 해제한다. 세션 이후에는 유휴 타이머로 해제한다. 화면 회전은 Worker 수명에 영향을 주지 않는다. 기기 내 인식 중 백그라운드에 들어가면 오디오를 중지하고 복귀 후 Resume으로 다시 연다.

## 완전 오프라인 경로

`/live`와 빌드 자산, 추론 JS·WASM·인식 점검 WAV는 전용 Shell Cache에 저장한다. 가중치는 별도 Cache Storage에 커밋 해시별로 저장한다. 설치 시 크기와 SHA-256을 검사하고 모든 파일이 준비된 리비전에만 완료 마커를 쓴다. 새 리비전은 이전 리비전의 데이터를 덮어쓰지 않는다. Preferences는 기존 저장소를 사용한다. 모델 바이트를 IndexedDB에 중복 저장하지 않는다. Worker 또는 런타임의 호환성이 바뀌는 릴리스에서는 정적 런타임 경로와 셸 버전을 함께 올린다. 가중치 리비전 마커는 다중 리비전을 분리한다.

다운로드 이후 준비 상태는 캐시의 필수 자산과 두 추론 샘플을 점검한 뒤 표시한다. 앱 셸/런타임은 동일 출처에서 제공하고 Worker의 추론용 원격 모델 로딩은 비활성화한다. Offline Mode는 음성·번역·성경 원문 조회·클라이언트 통역 텔레메트리의 서버 경로를 중단한다. 지원되는 장치에서 연결을 잃으면 기존 턴을 재큐잉하고, 기기 내 인식을 시도한다. 한번 오프라인으로 바뀐 세션은 연결이 복구돼도 자동으로 음성을 다시 전송하지 않는다. 원격 휴대폰 마이크는 기존 온라인 기능으로 유지한다.

이미 연결된 원격·클라우드에 장애 직전 전송된 바이트는 되돌릴 수 없다. 연결 상태만으로 포털이나 LAN 인터넷 장애를 감지하지 못할 수 있다. 이 경우 번역은 기존 요청 예산 이후 로컬 폴백이 작동한다. 완전히 로컬로 고정하려면 세션 시작 전에 Offline Mode를 사용한다.
