# 교회 파일럿: 3개 교회 × 4주

ASAD를 "한국교회 통역 봉사자를 위한 AI 통역 어시스턴트"로 특화시키는 첫 현장 검증.
목표는 기능 자랑이 아니라 **봉사자가 실제로 예배 통역을 맡을 수 있게 되는가**이다.

## 파일럿 구성

| 교회 | 규모 | 통역 시나리오 |
|------|------|---------------|
| A교회 | 중형 (출석 300) | 주일 2부 예배 설교 + 수요 기도회 |
| B교회 | 대형 (출석 2,000) | 영어권 방문자 Counter Mode 안내데스크 + 청년부 수련회 |
| C교회 | 소형 (출석 80) | 성경공부 + 외국인 근로자 대상 예배 |

- 기간: 4주. 1주차는 온보딩(준비 시트 작성, 용어집 확인), 2–4주차 측정.
- 통역 봉사자: 교회당 2–3명. ASAD 경험이 없는 봉사자를 우선한다 — 숙련자가 아닌 초보 봉사자의 실패율이 이 프로젝트의 진짜 지표다.
- 각 교회에 `feat/church-interpreter-pack`의 신학 용어집 팩(한→영·중 79개 표준 용어)과 교회 모임 프리셋(예배/설교/기도회/성경공부/수련회)이 적용된 빌드를 제공한다.

## 목표

1. **용어 정확도**: 설교 중 핵심 신학 용어(칭의, 성화, 중생, 속죄, 대속 등)가 표준 번역으로 통역되는 비율 90% 이상.
2. **통역사 만족도**: "다음 주에도 이 도구를 쓰고 싶다" 4점/5점 이상 (봉사자 설문).
3. **Counter Mode 안내데스크 활용도**: 예배 전후 안내데스크에서 외국인 방문자와의 실제 응대 세션 주당 5건 이상, 세션 완수율 80% 이상.

## 측정 지표

### 1. 용어 정확도 (Terminology accuracy)
- 방법: 2–4주차 설교 녹취에서 신학 용어집 팩의 79개 용어가 등장한 구간을 추출 → 봉사자의 실제 통역과 비교.
- 분자: 표준 번역(팩의 en/zh)과 일치한 용역 / 분모: 등장한 팩 용어 수.
- 자동 집계: `promptGlossary`에 주입된 용어와 최종 청크의 일치율을 세션 로그에서 계산. 사람이 20% 샘플링으로 검증한다.
- 목표: 90% 이상. 85% 미만이면 용어집 팩의 해당 항목을 교회별 피드백으로 개정한다 (데이터 파일만 교체, 엔진은 그대로).

### 2. 통역사 만족도 (Interpreter satisfaction)
- 매주 예배 후 5문항 설문 (5점 척도):
  1. 용어 제안이 도움이 되었는가
  2. 성경 구절 참조가 정확했는가
  3. 상황 판단(예배/기도회/성경공부)이 맞았는가
  4. 통역 흐름을 방해하지 않았는가 (temporal locking 체감)
  5. 다음 주도 사용하고 싶은가
- 목표: 전체 평균 4.0 이상, 문항 4번 4.5 이상 (방해하지 않는 것이 존재 이유다).
- 3점 이하 응답은 사유를 필수 기재 → 주간 리뷰에서 원인 분류 (용어/상황판단/UI/음성).

### 3. Counter Mode 안내데스크 활용도 (Counter Mode info-desk usage)
- B교회 안내데스크에 Counter Mode QR 상시 비치. 측정: 주당 세션 수, 평균 세션 길이, 세션 완수율(중도 이탈 없이 종료).
- 목표: 주당 5건 이상, 완수율 80% 이상.
- 세션 종료 후 방문자 대상 1문항: "안내를 이해했는가" (예/아니오). 목표 85% 이상 "예".

## 주차별 운영

- **1주차 — 온보딩**: 준비 시트 작성법 교육 30분, 용어집 팩의 표준 번역 확인 (교단별 이견이 있는 용어는 사전에 표시), Counter Mode QR 설치.
- **2주차 — 첫 실전**: 봉사자 1명이 통역, 1명이 관찰·메모. 관찰자는 용어 미스·상황 오판을 기록한다.
- **3주차 — 교대**: 역할 교대. 2주차 이슈 중 상위 3건을 수정한 빌드 재배포 (용어집 데이터 수정이 대부분일 것).
- **4주차 — 독립 운영**: 운영팀 개입 없이 봉사자만으로 진행. 이 주의 지표가 파일럿의 최종 성적이다.

## 성공/실패 기준

- 성공: 세 지표 모두 목표 달성 → 다음 분기 10개 교회로 확대.
- 조건부: 2개 지표 달성 → 미달 지표의 원인을 특정하고 2주 연장.
- 실패: 1개 이하 달성 → 포지셔닝 재검토. "특화가 통역 봉사자의 실제 병목을 풀지 못했다"는 결론을 문서로 남긴다.

## 리스크

- **교단별 용어 이견** (예: 권사, 전도사의 영어 표기): 팩의 `note`에 대안을 명시하고, 교회별 준비 시트에서 덮어쓸 수 있게 한다. 준비 시트 > 용어집 팩 순위는 엔진에 이미 구현되어 있다.
- **봉사자의 과의존**: 용어 제안은 "참고"이지 "정답"이 아님을 온보딩에서 강조. 만족도 문항 4번이 이를 감시한다.
- **개인정보**: 설교 녹취는 교회 내부 저장만, 외부 전송 금지. `docs/prep-privacy.md`의 원칙을 따른다.
