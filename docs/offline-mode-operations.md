# 오프라인 모드 운영

1. 인터넷이 연결된 HTTPS 환경에서 `/live`의 고급 설정을 연다.
2. 번역만 준비하려면 **Download translation model**을 누른다. 음성과 번역을 함께 준비하려면 **Download Offline Models**를 누른다.
3. **Offline Ready**가 표시되면 **Offline Mode**를 켜고, 한국어 → 영어를 선택해 기기 마이크로 시작한다. 자동 번역 설정에서는 클라우드 실패나 쿼터 소진 시 준비된 로컬 번역이 작동한다.
4. 첫 사용 전 짧은 음성으로 점검한다. 기기 내 인식은 휴지 또는 청크 길이에 따라 한 번에 텍스트를 표시한다.
5. **Unavailable**이면 설정에 표시된 오류를 확인하고 인터넷 연결 후 준비를 다시 실행한다. 다운로드를 중단한 경우 검증된 파일부터 재사용한다. 재설치가 필요하면 세션을 종료하고 **Delete Cached Models**를 사용한다.

지원되지 않는 언어의 경우 기존 온라인 인식과 번역을 사용한다. 원격 휴대폰 마이크를 쓰던 세션은 기기 마이크로 자동 전환하지 않는다. 오프라인 모드에서 음성과 텍스트는 기기 안에서만 처리하며 기존 이력 저장은 사용자 설정에 따른다.

## 배포와 롤백

기존 Next.js/Vercel 프로젝트를 사용하며 필수 환경 변수 변경은 없다. `npm run build`가 공개 런타임 파일을 같은 출처에 준비한다. Vercel 운영 환경의 변수는 이름만 조회했다. Preview에서 기존 인증과 무료 공급자 정책을 확인하고, 실제 iPad 절차를 통과하기 전에는 운영 배포를 승격하지 않는다. 새 API 자격 증명, 과금 공급자, GPU 서버는 필요하지 않다.

기능 결함의 경우 사용자는 **Offline Mode**를 끄고 기존 인식 경로를 선택할 수 있다. 릴리스 롤백은 Vercel에서 직전 검증된 Production 배포로 되돌리거나 병합 이후 커밋을 되돌린다. 브라우저에 내려받은 모델까지 삭제하려면 기기에서 캐시 삭제를 실행한다.
