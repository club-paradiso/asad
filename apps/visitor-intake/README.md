# 방문 목적 안내 키오스크 · 시범용

독립적인 정적 웹앱입니다. ASAD의 Next.js 프로덕션 빌드와 분리돼 있습니다.

## 기능
- 12개 언어 / 언어당 20개 방문 목적, 기존 Figma V5 문구 기반
- HiKorea 예약 여부 자기신고(예약함 / 예약 안 함 / 잘 모르겠음)
- 별도 인증, 로그인, 서버, 데이터베이스, STT, 저장소, 분석 도구, 쿠키 없음
- iPad Safari 터치 UI 및 화면 초기화
- ‘전화번호(연락처) 변경 신고’는 **방문 목적 선택**에 한함. 전화번호 입력이나 실제 변경 신고는 이 데모에서 처리하지 않음

## GitHub Pages
1. PR을 병합합니다.
2. Settings > Pages > Source를 **GitHub Actions**로 선택합니다. 기존 Pages 사이트가 존재하면 **배포가 덮어쓸 수 있으니** 먼저 확인하세요.
3. Actions > Visitor Intake - GitHub Pages (manual) > Run workflow.
4. 화면에 나타나는 실제 deployment URL을 열어 확인합니다.

수동 트리거만 적용했으며, main에 병합하는 것만으로 자동 배포하지 않습니다.
GitHub Pages가 일반적으로 쓰는 URL 형식은 https://club-paradiso.github.io/asad/ 이지만, 실제 설정을 검증하기 전에는 활성 주소로 간주하지 마세요.

## 로컬 실행
apps/visitor-intake 디렉터리에서 python3 -m http.server 8080 을 실행하고 http://localhost:8080/ 을 엽니다.

## 중요한 제한
**공개용 정적 안내 페이지**일 뿐, 직원 데스크톱으로 선택 내용이 전송되지 않습니다. 예약 검증이나 번호표 발급을 수행하지 않습니다.
GitHub Pages의 경로를 숨기는 것은 인증이 아닙니다. 직원용 화면을 Pages에 게시하지 마세요.
원본 기관 로고가 들어가 있으므로 기관 승인 없는 실사용·공식 서비스 오인은 금지하며, 시범 안내 표시를 유지해야 합니다.
민원인 여권번호·외국인등록번호 등 식별정보를 입력받거나 수집하지 않습니다.
12개 언어는 Figma 교정 초안이며 원어민·실무 검수가 필요합니다.
실시간 동기화와 음성 입력은 다음 단계에서 인증된 ASAD 서비스/서버로 구현해야 합니다.

## 2026-11-19: 완전 오프라인 단일 HTML · 공용 소통 화면

`index.html` **한 개만** PC에 내려받아 Edge/Chrome/Safari에서 `file://` 로 열면 됩니다. 별도 설치·서버·Wi-Fi·Vercel·Redis·외부 폰트·API 요청이 없습니다. PR #175에서 병합된 UI/번역 데이터(12개 언어 × 20개 업무), 직원 한국어 병기, 전화번호 변경 선택지, 개인정보 비수집 설계를 포함합니다. 이미지·스타일·번역·코드는 모두 HTML에 내장돼 있습니다.

- 직원 모니터: `index.html` 열기 → **보조 모니터 열기** 클릭 → 새 창을 보조 모니터로 옮기기 → 민원인과 동일한 선택 화면을 사용.
- 두 창은 **동일한 PC의 단일 브라우저 세션**에서 버튼 클릭 상태를 공유합니다. 어느 화면에서 눌러도 양쪽에 반영됩니다. 직원 모니터에는 추가 도구 모음이 있고, 방문객 화면에는 업무 선택 내용만 나옵니다.
- 인터넷 없이 별도 iPad에 HTML을 여는 것은 가능하지만, **서로 다른 기기끼리 자동 동기화되지는 않습니다.** 직원 PC와 iPad 사이 전송이 필요하다면 기관이 승인한 연결이 별도로 필요합니다.
- 방문예약 여부는 **민원인 자기신고**이며 기존 예약 확인 기록 플랫폼을 대체하지 않습니다. 실제 신고/예약확인/번호표 발급/전화번호 변경을 수행하지 않습니다.
- 이름·여권번호·연락처를 입력받지 않고, 전송·저장하지 않습니다. 선택 상태는 창을 닫으면 사라집니다. 완료 화면은 30초 후, 선택 중에는 무동작 120초 후 초기화됩니다.
- 창구 PC에서 외부 HTML 파일 사용·보조 모니터 연결이 기관 보안 정책에 의해 허용되는지 확인한 후 사용하세요. 직원 업무 화면이 민원인에게 노출되지 않도록 창 위치를 확인하세요.
- 라이브 데모: GitHub Pages가 활성화된 경우 `https://club-paradiso.github.io/asad/` 에 `index.html`이 배포됩니다. 저장소의 Pages 설정과 Actions의 성공 여부를 별도 확인하세요.
- 검증: `node scripts/e2e-intake-standalone.mjs` (Chromium/WebKit `file://` E2E, 오프라인 네트워크 요청 차단, 양방향 보조창 동기화).
