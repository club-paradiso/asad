아무튼서로알아들었으면 된거아닌가요

말은 완벽하지 않아도 소통은 성공할 수 있다. 이 제품은 정확한 언어를 팔지 않는다 — 언어가 어긋났는데도 대화가 통한 그 순간을 판다. 그래서 시각 시스템은 교정을 본 종이다: 따뜻한 종이 위의 잉크, 그리고 빨간 교정 표시. 틀린 말은 줄 아래에 그대로 읽힌다.

Colour

Ink is the action colour. Signal red is the correction mark — the ?, an error, a struck word — and never a routine button, which is what lets one value serve the brand and the error state without ambiguity. A red button in this product always means something is wrong.

Two surfaces

One dark surface and one paper surface, each locked regardless of the OS theme. Components reference only the working tokens, so the same component is correct on either without knowing which it is on.

Typography

Both webfonts are Latin-only and self-hosted at build time — Hangul stays on the device's own Korean stack, because a browser resolves fonts per character and the faces already on the phone beat a megabyte of CJK subsets downloaded ninety seconds before a service.
